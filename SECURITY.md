# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through [GitHub Security Advisories](https://github.com/glimps-re/dsvs/security/advisories/new): the report is visible only to the maintainers, and the fix and the advisory are prepared there before anything is made public.

Include what you can of the affected version (`dsvs --version`), the steps to reproduce, and the impact you see.

## Supported versions

Fixes go into the latest stable release. Betas are previews and are not maintained separately.
